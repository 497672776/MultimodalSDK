图像解码 + Qwen2-VL 归一化

mm.Image 解码 → mm.Tensor → mm.core.processor.resize_and_normalize（smart resize 到 28 的整数倍、/255、按 mean/std 归一化）。

视频解码 / 抽帧

mm.acc.video_decode：可均匀抽帧（sample_num）或指定帧号（frame_indices，空格或逗号分隔）。

音频加载

mm.load_audio(path, sr)：仅支持 .wav，返回一维 float32 波形与采样率。

SCC 视觉 token 压缩

mm.core.scc.scc_compress_to_target：按目标 token 数做语义连通分量合并。CPU 后端没有视觉编码器，演示用每 28×28 patch 的颜色/纹理描述子代替真实特征。

视觉问答（llama-server）

图片先经 mm 解码与缩放，再以 base64 发送给 K3 上的 llama-server（Qwen3-VL + mmproj）。
